A color generator creates color values that can be used in digital designs, websites, thumbnails, logos, graphics and other creative projects.

What is a HEX Color Code?

A HEX color code is a common way of representing colors in digital design. It normally starts with a # symbol followed by six hexadecimal characters.

For example:

#38BDF8

The first two characters represent red, the next two represent green and the final two represent blue.
